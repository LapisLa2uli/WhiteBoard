# WhiteBoard wiki

WhiteBoard is a personal desktop app for **your own** Blackboard account. It is not a replacement for Blackboard: it loads your courses, deadlines, grades, and files into a local dashboard, and opens the real Blackboard site when you need to submit work.

## At a glance

1. Sign in with school URL, username, and password.
2. Use the **top bar** to move between Home, Assignments, Submitted, Ignored, Grades, Contents, Calendar, and Settings.
3. Use the **left sidebar** to search courses, filter by activity, and build named course lists.
4. **Click** an assignment card for details. **Double-click** it to open that item in Blackboard.
5. **Refresh** reloads from Blackboard. If the session expired, WhiteBoard signs in again using the password still in memory.

The password is never saved to disk. Ignored items and “mark as submitted” flags are **local** — they do not change anything on Blackboard.
